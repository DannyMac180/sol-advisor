# scripts/ — repository verifiers

## Scope

Verifiers and operator procedures for the **Prime Agent** side of this repository. The
Codex plugin has its own verifier at `plugins/sol-advisor/scripts/verify.sh`; do not
extend or couple it from here. An empty base diff for `plugins/` and `.agents/` proves
this package contribution did not modify that lane. Any inherited plugin-verifier
failure belongs in a separate issue and PR.

## What is here

| Script | What it does | Spends quota |
|---|---|---|
| `verify-prime-agent-package.sh` | 20 checks over the package | no |
| `live-smoke-delegation.sh` | Prepares one real delegation; prints, never spawns | the run does |

## verify-prime-agent-package.sh

```sh
sh scripts/verify-prime-agent-package.sh                    # everything
sh scripts/verify-prime-agent-package.sh --structural-only  # skip install + tests
```

Prime Agent is lenient by design: a broken manifest entry, a frontmatter name that
disagrees with its directory, or a wheel-packages list that disagrees with the source
directory does not raise — the skill degrades to markdown or vanishes from discovery
behind a load warning nobody reads. This script makes those failures loud.

Four checks are worth knowing about before editing them:

- **The install cycle redirects both variables.** The home variable alone does not
  isolate the kernel venv. Getting this wrong makes the gate rebuild the operator's real
  venv while reporting success.
- **The real home is compared by path and size**, not by a hash including mtimes.
  Unrelated prime-agent activity moves an mtime-inclusive hash with no content change.
- **The thinking/effort assertion matches host call sites, not the words.** Reading a
  transcript's `thinking_level_change` entries is how effort is legitimately observed; a
  naive word grep would ban the correct implementation.
- **It stays independent of the inherited Codex verifier.** Package contributions
  prove an empty `plugins/` / `.agents/` diff; baseline plugin failures are fixed in
  their own PR rather than widening this one.

It mutates no Prime Agent configuration and starts no interactive session.

## live-smoke-delegation.sh

The one gate that spends model quota. It refuses without
`--i-understand-this-spends-quota` and a full `provider/model` selector, and it
**prepares and prints — it never spawns.**

```sh
sh scripts/live-smoke-delegation.sh --i-understand-this-spends-quota provider/model
```

It builds a throwaway git repository, redirects both the home and the kernel venv to
temp directories, and copies only `auth.json` — a spawn must authenticate against real
credentials or it cannot resolve a model at all.

What it does **not** bound, and the script says so itself: the child runs with the
operator's own OS permissions. The throwaway repository is a convention about where it
should write, not a sandbox that stops it writing elsewhere.

## Conventions

- POSIX `sh`, not bash. Check with `sh -n <script>` before committing.
- Every check prints `ok`/`FAIL`/`skip` with the offending path named. A failure the
  operator cannot act on is not a failure report.
- A check that cannot run (no `uv`, no `prime-agent`) **skips with a reason** rather
  than passing silently. A silent skip reads as coverage.
