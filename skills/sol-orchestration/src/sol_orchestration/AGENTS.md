# sol_orchestration — module conventions

## Scope

The kernel-side callables. Import direction runs one way: `contract` → `config`/`home` →
`host` → everything else. Do not create a cycle; if a module needs something from
`preflight`, the shared piece belongs in `contract.py`.

## Module map, and the one thing each exists to prevent

| Module | Exists to prevent |
|---|---|
| `contract.py` | Free-text degradation kinds, and refusals with no remedy |
| `home.py` | Mistaking a redirected home for a redirected kernel venv |
| `config.py` | A default model reaching production by being the value nobody edits |
| `host.py` | A spawn without a selector inheriting the parent's expensive model |
| `preflight.py` | Confusing optional direct messaging with the recorded same-model restart path |
| `routing.py` | Routing on a guessed feature, or falling back to the session's model |
| `spec.py` | A child reporting completion through the orchestrator's context |
| `lifecycle.py` | A crashed delegation leaving no record |
| `evidence.py` | `ship` resting on an exit status a child could have gamed |
| `review.py` | A starved orchestrator judging a diff it never read |
| `packet.py` | Child text reaching a verdict-relevant field |
| `episodes.py` | A corpus that cannot separate a model from its conditions |
| `ledger.py` | A lost turn losing the delegation with it |
| `reader.py` | A version contract nothing can consume |

## Rules that are not style

- **Lazy runtime import.** `import rlm` only ever inside a function body. A module-level
  import makes the package unimportable outside a kernel — including the test run that
  proves it works.
- **`evidence.py` and `episodes.py` must never reach the host.** Tests read their source
  and fail on `host_request`, `find_models`, `spawn(`, `import rlm`. One model call in
  either inverts the economics the package exists to fix.
- **`Host.spawn` validates and delegates to `_spawn`.** Subclasses override `_spawn`
  only. A guard implemented per subclass is a guard one new subclass forgets.
- **Order in `Lifecycle.dispatch` is snapshot → open record → spawn.** A record opened
  after the handle returns loses every spawn that raised.
- **The tamper gate runs before the verification command executes.** Not after. The
  kernel runs commands with the operator's permissions.
- **Unreadable is never zero and never a bare null.** Omit the field and record a
  degradation naming why. A zero cost reads as a free delegation; a null effort reads as
  a session that ran at no effort.

## Docstrings carry the why

Every module here opens with what it prevents, not what it does. Keep that. Someone
changing this code in a year needs the failure mode, not a restatement of the signature.
