# sol-orchestration — the Prime Agent capability package

## Scope

Cost-routed delegation. An orchestrator that never reads a project file, workers drawn
from an operator-declared allowlist, deterministic checks in the kernel for free, and
one episode record per delegation.

**The episode corpus is the deliverable.** Everything else exists to produce it
honestly. A record that is missing, collapsed, or confounded cannot be backfilled — the
delegation it described is gone. Weigh changes here against that.

## Two faces, both authoritative

`SKILL.md` is not merely documentation of the Python. It is the workflow contract,
and its recovery path must state honestly which corpus guarantees disappear without
the package. **When you change behaviour, change `SKILL.md` in the same commit.** A
recovery path that implies raw spawns created valid episodes is worse than none.

## Hard constraints

- **`dependencies = []` stays empty.** `prime-agent-runtime` ships with Prime Agent and
  is not on PyPI; declaring it breaks every install outside the kernel venv, including
  the test run. Import `rlm` lazily inside the call.
- **Every module must import outside a kernel.** Tested, and checked by the verifier.
- **No model name anywhere in source.** A test scans every module.
- **No thinking or effort host request.** No handler exists.
- The wheel-packages list, the directory name, the frontmatter `name:`, and the import
  identifier must all agree. Prime Agent will not tell you when they do not.

## Testing conventions

- **Write the failing test first**, then the code.
- **Mutation-check anything load-bearing.** Break it on purpose and confirm a test
  fails. Several defects here were found by a test that passed with the behaviour
  deleted — a green suite proves nothing until you know what it catches.
- **Integrate, do not only unit-test.** The worst defect in this package's history was
  the lifecycle and the ledger agreeing on a protocol but not a payload; both suites
  were green throughout.
- Evidence tests build **real git repositories**. Faked git output proves the parser
  works and nothing about whether the signal is real.
