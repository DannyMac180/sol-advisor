# tests/ — conventions

## Scope

258 tests, all free. No test spends model quota; the recording double in `conftest.py`
answers every host request.

## The double is the point

`RecordingHost` records the **shape of the traffic**, not just return values — which
queries were issued, what a spawn carried, what was never sent. That is what lets a test
assert "availability was resolved one entry at a time and never as one enumeration",
which no return-value assertion could.

It deliberately reproduces the runtime's own twenty-result search cap. A double that
returned everything asked of it would make the cap invisible, and the per-entry-query
test would prove nothing.

`FakeClock` exists so a timeout is provable without waiting for one. A test that proves
a bound by actually sleeping is a slow test that eventually gets deleted.

## Rules

- **Failing test first.** Always.
- **Mutation-check anything load-bearing.** Break the behaviour on purpose; confirm a
  test fails; restore. A test that passes with the code deleted is decoration. Two
  defects in this package were found exactly that way.
- **Order assertions so the discriminating one fires first.** The tamper-gate test
  asserts the command left no marker *before* it asserts the verdict, because only the
  marker distinguishes preventing execution from classifying after it.
- **Real git repositories** in evidence tests. `git init`, real commits, real `git
  status`. Faked output tests the parser, not the signal.
- **Integrate across module boundaries.** Both suites can be green while the two modules
  disagree on a payload — that has already happened here.
- Every test name states the claim. `test_a_spawn_that_raises_still_closes_an_episode`
  tells a reader what breaks; `test_spawn_error` does not.

## Running

```sh
uv run --with pytest python -m pytest -q
uv run --python 3.14 --with pytest python -m pytest -q -W error
uv run --python 3.11 --with pytest python -m pytest -q -W error
```

Clear `__pycache__` between mutation runs — a stale one has already produced a
convincing false failure.
